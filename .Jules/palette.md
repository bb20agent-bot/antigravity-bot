## 2024-05-27 - Added Accessible Copy Button\n**Learning:** Implementing clipboard copy functionality in embedded webviews (like Telegram Mini Apps) often requires a robust fallback to `document.execCommand('copy')` because `navigator.clipboard` may be undefined or reject promises in insecure contexts. Furthermore, because system-level toast notifications might not appear consistently across different mobile OS environments, providing inline visual feedback (e.g., swapping a Copy icon for a Check icon) and dynamically updating the `aria-label` ensures both visual and screen-reader users receive confirmation of the action.\n**Action:** When adding copy to clipboard buttons in Telegram Mini Apps, always use a fallback mechanism with a temporary textarea (with `readOnly=true`), swap the icon for visual feedback, and update the `aria-label` to communicate success to assistive technologies.
