## 2024-05-18 - [Telegram Mini App Clipboard Fallback & Feedback]
**Learning:** System-level toast notifications are unreliable in Telegram Mini Apps when copying to clipboard. Furthermore, `navigator.clipboard.writeText` often fails in embedded webviews due to insecure context restrictions or permission errors. Standard fallback mechanisms without `readOnly = true` on dynamic inputs can inadvertently trigger the mobile virtual keyboard, causing bad UX.
**Action:** Always provide inline visual feedback (e.g., swapping icons) and dynamic `aria-label` updates for clipboard actions instead of relying on toasts. For the copy fallback, always set `readOnly = true` on the dynamically created `textarea` element to prevent the virtual keyboard from popping up, and conditionally execute it inside the `.catch()` block or if `navigator.clipboard` is unavailable. Extract this logic into small components (e.g., `CopyButton`) to avoid full application re-renders when the state (`isCopied`) changes.
