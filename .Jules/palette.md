## 2024-05-24 - [Clipboard Copy Fallback in Telegram WebApp]
**Learning:** In Telegram Mini Apps (and other embedded WebViews or insecure contexts), `navigator.clipboard.writeText` often fails due to permission restrictions or missing secure context. The existing copy button in the Fandom Link section lacked both a fallback mechanism and visual success feedback, leading to silent failures where users couldn't copy their links. Providing a visually explicit confirmation (e.g. swapping the icon to a Check mark) is critical because system-level toast notifications are unreliable in these environments.
**Action:** Created a reusable `CopyButton` component that implements a robust fallback using `document.execCommand('copy')` with a temporary `textarea`. Ensured the fallback is only called if `navigator.clipboard` is missing or its promise is rejected. Added explicit inline visual feedback (swapping the `Copy` icon to a `Check` icon and updating the color to green) and updated the `aria-label` to communicate the success state to screen readers. Kept the temporary state contained within the small component to avoid re-rendering the massive `UserApp` component.
