## 2026-05-30 - Fallback Copy Implementation in Telegram Mini Apps
**Learning:** System-level toast notifications and clipboard APIs are unreliable in Telegram Mini Apps. Fallbacks using `document.execCommand('copy')` with a hidden, dynamically created textarea are necessary. Always set `readOnly = true` on the fallback textarea to prevent the virtual keyboard from popping up and jarring the user experience. Moreover, avoid tying micro-interaction states (like copy success) to the root app state in massive components to prevent expensive re-renders.
**Action:** Extract micro-interactions like clipboard copy into separate, smaller functional components (e.g., `CopyButton`) to isolate state, and always implement a robust fallback mechanism with visual inline feedback (e.g., swapping icons) instead of relying on native toasts.
