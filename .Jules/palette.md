## 2024-05-24 - [Clipboard UX Pattern for Telegram Mini Apps]
**Learning:** Using `navigator.clipboard.writeText` fails in embedded webviews like Telegram Mini Apps (TMA) when they run in insecure contexts, requiring a synchronous fallback via `document.execCommand("copy")` with a dynamically created `<textarea>`. Additionally, system-level toast notifications are unreliable in TMAs, so visual inline feedback (like dynamically updating an `aria-label` and swapping a `Copy` icon for a `CheckCircle` icon colored green) provides necessary UX confidence for clipboard operations.
**Action:** When implementing copy functionality in TMA projects, always employ the `document.execCommand` fallback pattern inline synchronously. Ensure visual feedback and accessibility state (like `aria-label`) are handled within the component state to guarantee user feedback regardless of platform-level toast support.
