## 2024-06-07 - [Telegram Mini App Clipboard Fallback]
**Learning:** [UX/a11y insight] In Telegram Mini Apps, `navigator.clipboard.writeText` often fails silently or reliably throws an error due to the restricted environment/permissions context. Simply executing `document.execCommand('copy')` as a fallback unconditionally can cause duplicate permission prompts or race conditions. A visual toast notification using browser defaults isn't reliable either.
**Action:** [How to apply next time] Always use a robust try/catch approach where the fallback uses a dynamically created `textarea` with `readOnly = true` (to prevent the virtual keyboard from popping up). Combine this with explicit, inline visual feedback (swapping a Copy icon to a Check icon) and dynamic `aria-label` updates rather than relying on system toasts.
