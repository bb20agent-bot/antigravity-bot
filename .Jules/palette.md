## 2026-05-23 - Clipboard API Fallback for Telegram Mini Apps
**Learning:** The modern `navigator.clipboard` API is frequently blocked or fails silently inside embedded webviews like Telegram Mini Apps (TMA) because they do not always execute in a secure context or fully support modern browser permissions. Additionally, system-level toast notifications are unreliable in these environments.
**Action:** When implementing copy-to-clipboard functionality, always include a fallback mechanism using `document.execCommand("copy")` with a dynamically created, visually hidden `textarea`. Furthermore, explicitly provide inline visual feedback (e.g., swapping icons) and dynamically update `aria-label` attributes to ensure the user receives clear confirmation of success, rather than relying on system toasts.
