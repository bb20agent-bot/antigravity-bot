## $(date +%Y-%m-%d) - Telegram Mini App Clipboard UX
**Learning:** In Telegram Mini Apps (and sometimes standard embedded webviews), `navigator.clipboard.writeText` often fails due to secure context restrictions or permission policies. Additionally, system-level toast notifications can be unreliable. Providing a resilient fallback using a hidden `<textarea>` with `document.execCommand('copy')` is critical. Furthermore, inline visual feedback (like swapping a copy icon for a checkmark) is essential for informing the user of success instead of relying on unpredictable system toasts.
**Action:** When implementing copy-to-clipboard functionality, always include a hidden textarea fallback and provide clear, in-component visual feedback to ensure a smooth UX across restrictive environments like Telegram Mini Apps.
