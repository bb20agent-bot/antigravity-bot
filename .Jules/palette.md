## 2026-06-09 - [Clipboard Copy with Telegram Mini App Fallbacks]
**Learning:** Telegram Mini Apps and embedded webviews often run in insecure contexts or restrict `navigator.clipboard` access, causing standard modern copy APIs to silently fail. Additionally, system-level toast notifications are unreliable in this environment. Using `document.execCommand('copy')` with a dynamically created, hidden, read-only textarea provides a robust fallback. Acknowledging memory rules, it's also critical to supply inline visual feedback (swapping the Copy icon to a Check mark) and update `aria-label` attributes to ensure accessibility and clear UX without relying on unreliable system toasts. Extracting this into a small reusable `CopyButton` prevents flooding the root component with localized micro-state.
**Action:** Implemented a reusable `CopyButton` component that pairs `navigator.clipboard` with a `document.execCommand('copy')` fallback strategy. Includes state-driven visual feedback (icon swap) and dynamic `aria-label` updates to guarantee success communication directly within the UI. Abstracted this from `UserApp.tsx` to keep the main component lean.
