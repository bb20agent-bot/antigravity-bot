## 2024-10-14 - Add CopyButton with ARIA label and fallback
**Learning:** Found an inline `<button>` used for copying a Fandom Link in `user/UserApp.tsx`. It lacked proper `aria-label` for screen readers and did not have robust fallback behavior (e.g. using `document.execCommand('copy')`) or a clear accessible focus state for keyboard users (`focus-visible:ring-2`). Additionally, putting transient UI state (`isCopied` timeout) directly into `UserApp.tsx` (which is >1600 lines) causes massive re-renders.
**Action:** Created a reusable `CopyButton` component that properly encapsulates the state, uses `aria-label` that dynamically updates on success ("Copy referral link" -> "Copied to clipboard"), handles secure/insecure context fallback for clipboard copying in Telegram Mini Apps, and applies `focus-visible` ring. Replaced the inline button in `UserApp.tsx` with this component.
