## 2024-07-03 - [Telegram Mini Apps Clipboard Fallback]
**Learning:** System-level clipboard toast notifications are unreliable or non-existent in Telegram Mini Apps and other embedded webviews. Using `navigator.clipboard` without an inline UX fallback leads to silent failures or invisible successes, breaking the user flow. Additionally, `document.execCommand('copy')` is necessary when `navigator.clipboard` is missing or in an insecure context, but requires specific workarounds (like `readOnly=true` and `-9999px` absolute positioning) to prevent virtual keyboards and scrolling jank.
**Action:** Created a reusable `<CopyButton />` component that standardizes clipboard interactions by managing its own visual state (swapping Copy to Check icons), handling timeout resets cleanly using `setTimeout`, providing dynamic `aria-label` updates for screen readers, and incorporating a robust `textarea` fallback for TMA environments without breaking layout.
