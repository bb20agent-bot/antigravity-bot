## 2023-10-25 - Dynamic Class Resolution Conflict in Reusable Components
**Learning:** When creating reusable UI components (like `CopyButton`) that accept an `iconClassName` prop for external styling, directly appending state-based utility classes (e.g., `text-green-500 ${iconClassName}`) can cause CSS specificity conflicts in frameworks like Tailwind. For instance, if the parent passes `text-white`, both classes will be applied to the DOM element, and source order will dictate the color, often breaking intended visual feedback.
**Action:** When overriding injected utility classes based on internal component state (like hover or success), either use a CSS-in-JS utility like `tailwind-merge`/`clsx` to resolve conflicts, or strategically strip conflicting text-color classes using a regex (e.g., `.replace(/text-\w+(-\d+)?/g, '')`) before appending the new state class.
