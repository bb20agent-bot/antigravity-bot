## 2024-06-05 - [Telegram Mini App Clipboard & Micro-Interaction Performance]
**Learning:** System-level clipboard notifications are unreliable or suppressed inside embedded webviews like Telegram Mini Apps. Without inline visual feedback, users repeatedly click copy buttons out of uncertainty. Furthermore, implementing UI feedback timers (e.g., swapping a Copy icon to a Check icon for 2 seconds) directly inside massive root components (>1500 lines) causes severe performance bottlenecks due to full application re-renders.
**Action:** Extract micro-interactions that require rapid state changes (like `isCopied` timers) into isolated, small functional components (e.g., `<CopyButton>`). Combine this with an explicit fallback mechanism using `document.execCommand('copy')`, dynamic `aria-label` updates ("Copied"), and Telegram-specific haptic feedback to guarantee a smooth, accessible, and performant user experience in constrained environments.
