## 2023-11-03 - [TMA Webview Copy Mechanism]
**Learning:** System-level toast notifications are unreliable in Telegram Mini Apps (TMA) and embedded webviews. Using `document.execCommand('copy')` as a fallback alongside `navigator.clipboard.writeText` is essential due to permission restrictions in these contexts. When implementing the fallback, dynamically creating a `textarea` with `readOnly = true` prevents the virtual keyboard from popping up, and using `position: 'absolute'` with `left: '-9999px'` prevents layout jumps when `.select()` is invoked.
**Action:** When implementing copy-to-clipboard functionality in this TMA, always abstract it into a reusable component (like `CopyButton`) that implements both the modern clipboard API and the `execCommand` fallback, along with inline visual feedback (e.g., swapping the icon to a checkmark) and ARIA state updates.
