## 2024-11-20 - Telegram Mini App Clipboard Copy Pattern
**Learning:** `navigator.clipboard` is often blocked or unreliable within Telegram Mini Apps due to secure context restrictions or embedded webview limitations. Relying solely on this API causes silent failures when users attempt to copy text (like referral links), resulting in a poor user experience. Toast notifications also struggle in this environment.
**Action:** Created a reusable `<CopyButton>` component that provides an inline visual feedback mechanism (icon swap + `aria-label` update) instead of relying on toast notifications. It gracefully attempts `navigator.clipboard.writeText` first, and if it fails (via `.catch()`) or is unavailable, falls back to a dynamically created, hidden, and `readOnly` `textarea` using `document.execCommand('copy')`.
